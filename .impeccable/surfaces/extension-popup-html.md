# Extension popup

Mode: Operate. Surface: `extension/popup.html`.

The user-approved first delivery specifies a compact passage editor with keyboard-controlled typing and visible state. The popup must make paste → save → close → click → shortcut understandable, without a Start button that steals the destination's caret.

Direction contract: a quiet writing slip, pale paper ground and green ink, native system text for a browser utility, an uninterrupted passage area above a ruled status/control strip. First viewport shows the draft, local save status, time estimate, and both real shortcuts. The signature interaction is the progress rule filling only from acknowledged characters; opening the popup pauses the run and makes its exact offset legible. No invented compatibility claims or decorative imagery. Prioritize readable errors, keyboard focus, and the 380px popup boundary.

The explicit functional implementation plan governs this narrow surface; no image-led concept round or additional design decision is required for delivery.
